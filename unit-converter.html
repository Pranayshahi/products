Unit Converter — FAQs
How many feet in 1 meter? +
1 meter = 3.28084 feet. Select Length category, set From = m, To = foot, enter 1.
What is 1 acre in square feet? +
1 acre = 43,560 square feet. Select Area category, set From = acre, To = sqft, enter 1.
How to convert Celsius to Fahrenheit? +
F = C × 9/5 + 32. Select Temperature, From = C, To = F. For example, 37°C (body temp) = 98.6°F.
