⚙️ Technical SEO Checklist

Complete these technical tasks first — they are the foundation. Without them, good content won't rank.

✅ Already implemented in your website

  • Schema.org JSON-LD — WebApplication, FAQPage, BreadcrumbList, Organization, WebSite, ItemList on all pages
  • Canonical URLs — Every page has <link rel="canonical"> pointing to the correct URL
  • Open Graph tags — og:title, og:description, og:url, og:type on all pages for WhatsApp/social sharing
  • Twitter Card tags — summary_large_image type configured
  • Meta descriptions — Unique, keyword-rich, 140-160 characters on all pages
  • Title tags — Primary keyword + CalcAdda.in brand, under 60 characters
  • H1 tags — One per page, contains primary keyword
  • XML Sitemap — sitemap.xml covering all 16 pages + blog articles with priority and changefreq
  • Robots.txt — Allows all crawlers, references sitemap
  • Breadcrumbs — On all pages with schema markup
  • Internal linking — Related calculator links at bottom of content sections
  • Blog articles — 4 long-form articles targeting high-volume keywords
  • FAQ sections — 4–5 FAQs per page with schema markup (gets rich results in Google)
  • Mobile responsive — CSS uses relative units, media queries at 480px and 660px
  • External links — MF fund websites, bank apply links all have target="_blank" rel="noopener"

⬜ Do these yourself after uploading

  • Submit to Google Search Console — Add calcadda.in as a property. Submit sitemap URL. Takes 2–4 days for first crawl. search.google.com/search-console
  • Submit to Bing Webmaster Tools — Free, adds Bing + DuckDuckGo traffic. bing.com/webmasters
  • Create OG image (og-image.png) — 1200×630px branded image for social sharing. Use Canva. Upload to calcadda.in/og-image.png
  • Set up Google Analytics 4 — Add GA4 tracking code. Monitor which pages get traffic, bounce rate, session time
  • Enable HTTPS — Your host (Hostinger) provides free SSL via Let's Encrypt. Enable in hosting control panel. HTTPS is a ranking signal.
  • Page speed — compress CSS — Use cssnano.co to minify style.css. Target: under 50KB. Currently ~18KB (already good)
  • Add favicon.ico file — Create a proper .ico file from the SVG inline favicon. Upload as favicon.ico to root
  • Update sitemap dates — Change 2026-03-30 to the actual upload date when you go live
  • Set up Google Business Profile — Even for a website, a Google Business listing adds trust signals and can appear in Knowledge Panel
  • Apply for Google AdSense — Once you hit 30+ daily visitors, apply at adsense.google.com. Approval takes 2–4 weeks

🏆 Google SERP Features You Can Win

1. Featured Snippets (Position Zero)

The box that appears above search results. CalcAdda pages are structured to win these for:

  • "How is EMI calculated?" — Your EMI formula section with the clean formula box
  • "How to convert CGPA to percentage?" — Your CGPA page has a direct answer: "CBSE: CGPA × 9.5"
  • "What is FOIR?" — Your loan eligibility page has a concise definition
  • "GST rate on services India" — GST page with the rate table
To win featured snippets: Answer the question in the first sentence after the H2/H3 heading. Keep the answer to 40–60 words. Tables and numbered lists are especially likely to be featured.

2. "People Also Ask" (PAA) — FAQ Rich Results

Every page has FAQPage schema markup with 4–5 questions. When Google shows "People Also Ask" for calculator queries, your FAQ schema makes you eligible to appear there. This doubles your visibility on the search results page.

3. Knowledge Panels

The Organization schema on every page, combined with a Google Business Profile, positions CalcAdda for a knowledge panel appearance as the site gains authority.

4. Sitelinks

As the site gains trust, Google may show sitelinks (multiple page links under the main result) for branded searches like "calcadda" or "calcadda emi calculator". The clean site structure accelerates this.
